## Projects

**[CuraLM: AI-Driven Personalized Medicine](https://github.com/Miray43/CuraLM)** (graduation project, team of 4)
Fine-tuned BioMistral-7B with QLoRA and added a FAISS-based RAG pipeline for drug details and top-drug suggestions. In the notebook evaluation, RAG raised generic-name exact match from 62.6% to 93.9%. The web UI is a static mock-up.
`Python` `PyTorch` `Hugging Face` `PEFT` `FAISS`

**[MediServe: Hospital IT Maintenance & Ticketing](https://github.com/Miray43/MediServe-Hospital-IT-System)** (team project)
Web system for tracking hospital IT devices, maintenance workflows and support tickets, with an Express/MySQL REST API of about 50 endpoints. I worked on the frontend, backend and database.
`Node.js` `Express` `MySQL` `JavaScript`
